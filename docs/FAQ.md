# 常见问题

**Q：显示「未检测到杜比全景声」，是不是手机不支持？**
A：不一定。厂商可能用私有通路，标准接口不暴露。以实际播放能否点亮为准。

**Q：显示支持 10bit，但播放时画面发灰？**
A：多为显示端没切进 HDR 模式，与解码无关。可对比播放器 HDR 开关。

**Q：为什么只显示一颗摄像头？**
A：`getCameraIdList()` 只给公开相机。本工具已补 `getPhysicalCameraIds()`，若仍只有一颗，说明该机型把物理镜头完全私有化。

**Q：点「查看」进去是父相机画面？**
A：厂商不允许物理镜头单独取流，已自动退回并在底部标注。

**Q：Root 版悬浮窗看不到内容？**
A：需授予悬浮窗权限并保持服务运行；部分 ROM 会限制后台服务，需在电池优化里放行。

**Q：为什么首次启动必须同意免责声明？**
A：有意设计。不同意即退出，避免误用检测结果。

**Q：标准版和 Root 版能同时装吗？**
A：能，包名不同。

**Q：打赏能退吗？**

**Q：会收集数据吗？**
A：不会。软件不联网、不含统计 SDK、不申请存储读写以外的敏感权限。

A：不允许，见 LICENSE。
